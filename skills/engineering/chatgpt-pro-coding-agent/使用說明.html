ChatGPT Pro Coding Agent

讓 Codex 擔任 repository owner、權限守門與獨立 QA，讓 ChatGPT Pro 透過 CodexPro MCP 完成深度工程工作，再由本機證據決定是否接受。

適合什麼情境

大型新功能、複雜重構、瀏覽器介面與需要較長推理的工程任務。小型單檔修改通常直接由 Codex 完成更快。

標準流程

1. Codex 讀取 AGENTS、README、Git 狀態與現有測試，寫出 acceptance criteria。
2. Camoufox 固定開啟 [EK] chatgpt-pro-coding-agent-0801 Project，驗證 project-specific composer；不得使用全域 New chat。
3. 以單一 workspace 啟動 CodexPro，使用 ChatGPT Pro Web 的 MCP app。
4. Pro 讀檔、修改與執行允許的檢查；新對話產生後回 Project Chats 清單確認歸檔。
5. Codex 檢查 diff、跑測試、啟動應用程式並做瀏覽器 QA；發現問題時在同一 Project conversation 要求最小修正。

可直接使用的 Prompt

請用 chatgpt-pro-coding-agent skill。
目標：在目前 workspace 實作 [功能]。
只修改：[明確路徑]。
驗收：[可觀察行為、測試、viewport、無 console error]。
不要 commit、push、deploy、migration 或讀取 secrets。
完成後請呼叫 show_changes，回報實際修改檔案與檢查結果。

固定 Project

https://chatgpt.com/g/g-p-6a6dc574a6848191962b3e91895353c1/project

若 Project 無法存取、已改名或找不到 New chat in [EK] chatgpt-pro-coding-agent-0801，流程必須停止，不得把任務送到一般聊天。

安全邊界

不要把 CodexPro connector URL、token、cookies 或登入資料寫入對話、檔案或截圖。若遇到登入、CAPTCHA、passkey 或 2FA，停下來讓使用者在瀏覽器中完成。

本 skill 不是 quota bypass、account sharing 或 model proxy。ChatGPT Pro 的輸出永遠只是候選實作；本機 runtime、測試與公開/API read-back 才是完成證據。
