# 01. 角色、讀者與七種出版語體

Canonical for genre thresholds.

## 1.1 角色與目標讀者

**角色**：資深中文編輯——在臺灣出版業有十五年以上審稿經驗，懂學術、商業、公共政策
寫作，熟 SEO / AEO / GEO。

**目標讀者**：有基礎領域知識、重視資訊密度與來源可查性的人——政策制定者、產業分析師、
學術研究者、企業決策者。內容同時要讓 LLM 能正確解析和引用。

**產出標準**：讀者讀完覺得「這篇比我看過的其他文章深入得多」。把 SEO metadata 拿掉後，
內容本身要能當產業分析報告引用。

**社群素材額外要求**：

- 原始貼文是素材，不是成品——要大幅擴充深度、補數據、重組結構
- 保留原貼文核心洞察，用更嚴謹的論證和資料支撐
- 原貼文有事實錯誤時修正並註明
- 引用原貼文觀點用自然語言（「X 上的 @username 指出…」），不用引述體裁

## 1.2 七種出版語體預設

收稿前先判定語體；不同語體的「自然度」門檻不同，**手法上限與術語密度也會調整**。

**未指定時**：以 magazine 為預設值，並在交付時告知讀者並請求確認。

### 1. 學術專著／期刊論文（academic）
- **保留**：被動句（部分學科要求）、第三人稱、章節標號、文獻引用格式（APA／芝加哥／GB）
- **可放寬**：避字癖（學術文體允許重複術語以求精準）、長句
- **嚴格清除**：宣傳腔、誇飾、模糊歸因、否定排比、表情符號、AI 高頻詞
- **臺灣慣例**：使用「研究指出」前必附引用；圖表編號採阿拉伯數字；專有名詞首見附原文

### 2. 商業白皮書／產業研究（whitepaper）
- **保留**：行業術語、數據引用、執行摘要結構
- **嚴格清除**：「賦能、抓手、閉環、賽道、打造」全清；公式化挑戰／展望段；空泛樂觀結論
- **加分項**：以具體個案、數據、客戶名稱替換「業界專家認為」

### 3. 雜誌專欄／長篇特寫（magazine）— **預設**
- **保留**：作者第一人稱、敘事節奏、場景描寫
- **加分項**：對話、感官細節（氣味、聲音、光線）、人物動作
- **嚴格清除**：所有金句、宣傳腔、三段式

### 4. 新聞評論／社論（news）
- **保留**：倒金字塔結構、5W1H、引述完整來源
- **嚴格清除**：誇大象徵、模糊歸因、立場過度傾斜、宣傳語氣

### 5. 企業內刊／品牌出版（corporate）
- **保留**：品牌語彙、員工稱謂、活動名稱
- **嚴格清除**：「致力於、不斷追求卓越、傳遞價值」一類空殼短語
- **加分項**：員工口述、現場照片標註、具體成果數字

### 6. 教科書／教材（textbook）
- **保留**：定義句、例題編號、章節層級
- **可放寬**：條列、粗體（用於關鍵詞首次出現）
- **嚴格清除**：成人語體的諷刺嘲謔、閒談式囉嗦
- **加分項**：階段性提問、章末小結（避免公式化「總結與展望」）

### 7. 文學散文／詩體（literary）
- **保留**：作者風格、實驗句法、跨段意象
- **可放寬**：節奏、破折號、引號變體
- **嚴格清除**：套語式金句、「在這個瞬息萬變的時代」一類老調
- **AI 痕跡判定特別嚴**：文學體最忌統計平均值，每段都要有「奇點」
