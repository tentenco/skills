# 07. 統一品質檢核（Pre-Output Gate）

Canonical for final checklists & scoring.

**交付前跑完以下三層檢核**：
1. Layer 1：Pattern Compliance（30 項 AI 痕跡 + 4 類硬上限）
2. Layer 2：Content Standards（深度、SEO、結構）
3. Layer 3：Soul Check（六維度評分）

**任一 Layer 未過 → 重寫對應段落。**
**整篇加權總分 < 70 → 全文重寫。**

---

## 12.1 Layer 1：Pattern Compliance Checklist

**寫作品質**
- [ ] 連續段落開頭沒用同一句式
- [ ] 4 類手法都在全文上限內（對比 ≤2、排比 ≤2、反問 ≤1、破折號 ≤3）
- [ ] 否定排比 = 0
- [ ] 30 項 AI 痕跡警示詞清查通過
- [ ] 沒有超過 40 字或含 3 個以上子句的句子
- [ ] 結尾不是口號或空泛願景
- [ ] 「的」字一句最多一個結構性使用

**臺灣化**
- [ ] 中港用語對照表清查（科技、商業、生活、學術四欄）
- [ ] 簡轉繁易錯字（著、群、為、內、裡、麼）正確
- [ ] 標點符號照教育部規範（「」、《》、〈〉、——、……）
- [ ] 中英之間有空格；數字與英文單位之間有半形空格
- [ ] 沒有用 「 」 包裹一般文字（只用在引述、特稱）

## 12.2 Layer 2：Content Standards Checklist

**內容深度**
- [ ] 至少 5 組可驗證具體數據
- [ ] 關鍵事件有精確日期（沒有「近期」「最近」）
- [ ] 至少 2 位具名人物或機構引用
- [ ] 比較表格欄位有具體數據（沒有「較強」「較弱」）
- [ ] 挖到商業結構細節（毛利率、客單價、收入結構）
- [ ] 引用來源都有完整 URL

**結構與格式**
- [ ] 引用標記和裝飾元素都移除
- [ ] 標題層級調整好（H1→H3）
- [ ] 連結建置符合政策：`quota_report` 預檢；每語言完整草稿只呼叫一次 `plan_links`；套用精確 span edits；3–5 個（或依終止結果接受更少）；同語言、無自連、無重複目標、在正文段落內
- [ ] CTA 自然且相關
- [ ] 沒有可砍的冗餘段落
- [ ] 長度跟標題承諾相符
- [ ] 術語一致性鎖定（>3,000 字稿件）

**AEO / GEO**
- [ ] 目標關鍵字出現在 5 個位置（Page Title、Meta Desc、URL、H1、首段首句）
- [ ] 前 150 字有 Answer Target Block（核心結論 + 數據 + 時間錨點）
- [ ] 3–5 個 FAQ 格式問答
- [ ] 專有名詞首次出現有完整定義
- [ ] 數據有時間標記
- [ ] 內容偏 bottom-of-funnel
- [ ] 技術附錄四區塊齊備：SEO Metadata、GA4 regex、多平台覆蓋建議、素材來源

**社群抓取品質**（僅有抓取時觸發）
- [ ] 原始內容完整抓取（Thread / 長文沒被截斷）
- [ ] 沒有平台 UI 殘留
- [ ] 原作者觀點被正確保留和引用（沒曲解）
- [ ] 已補足夠數據支撐原貼文觀點
- [ ] 原貼文引用的數據已追溯到原始來源

## 12.3 Layer 3：Soul Check（六維度評分，每項 1–10）

| 維度 | 1 分（差） | 10 分（出版級） | 得分 |
|------|------------|------------------|------|
| **直接性** | 充滿鋪陳、虛字、墊話 | 開門見山，無一贅句 | /10 |
| **節奏** | 句長機械整齊、段落收束公式化 | 長短交錯、收束方式多變 | /10 |
| **信任度** | 過度解釋、把讀者當小孩 | 簡潔明瞭、留白給讀者 | /10 |
| **真實性** | 機器味、無觀點 | 有作者口吻、有判斷 | /10 |
| **臺灣化** | 大量中港用語、對岸句式 | 完全臺灣慣用、無翻譯腔 | /10 |
| **術語一致** | 同一概念多種譯名混用 | 全篇統一、首見附原文 | /10 |
| **總分** | | | **/60** |

**Soul Check 判定**：
- **54–60**：可送印
- **45–53**：尚需一輪修改
- **36–44**：需要重構段落
- **< 36**：建議全文重寫

## 12.4 加權總分（換算 100 分）

| 項目 | 權重 |
|------|------|
| 事實可驗證 | 15% |
| 內容深度 | 20% |
| 內容密度（每段推進論點） | 8% |
| 手法合規（4 類硬上限 + 30 項 AI 痕跡） | 10% |
| 臺灣化 | 8% |
| 節奏自然 | 6% |
| 論證清楚 | 6% |
| Soul Check 評分（六維度均分 × 10） | 8% |
| SEO 優化（5 個位置） | 6% |
| E-E-A-T（權威來源 + 作者實務經驗） | 5% |
| AEO/GEO 優化 | 5% |
| Bottom-of-Funnel 導向 | 3% |

**閾值**：≥ 80 出稿；70–79 修弱項；< 70 全文重寫。
