## Part 6. 標點與排版規範（教育部《重訂標點符號手冊》）

### 6.1 標點符號

| 符號 | 用法 |
|------|------|
| `，` 逗號 | 分隔語意；不可連用三句以上不換句號 |
| `。` 句號 | 全形，置於右下 |
| `；` 分號 | 連結兩個對等子句 |
| `：` 冒號 | 引出引文、列舉、說明 |
| `「」` 單引號 | 一般引號；對話、引文、特稱 |
| `『』` 雙引號 | 引號中的引號（巢狀） |
| `《》` 書名號 | 書、期刊、報紙、影視作品名稱 |
| `〈〉` 篇名號 | 期刊單篇文章、書中單章 |
| `——` 破折號 | 占兩個全形字位；補充說明、急轉、總起下文 |
| `……` 刪節號 | 占兩個全形字位（六個小點）；省略、餘意 |
| `、` 頓號 | 並列詞語之間 |
| `．` 間隔號 | 外國人名譯名間隔（如「彼得．杜拉克」） |

### 6.2 中英夾雜

- 中英之間建議空一格（出版業偏好「空格派」）：「我使用 ChatGPT 寫稿。」
- 數字與單位之間：阿拉伯數字 + 半形空格 + 英文單位（「3 GB」「12 km」）
- 中文數字與量詞不空格：「三公里」「十二公分」

### 6.3 數字使用

- **概數、成語、時代**：用國字。「八九不離十」「五四運動」「七十年代」
- **精確數據、統計、年月日**：用阿拉伯數字。「2024 年 3 月 17 日」「成長 12.7%」
- **大寫國字**：法律、契約、財務文件。「新臺幣壹拾萬元整」

### 6.4 著重號

需要強調某個詞時，可用著重號（字下加點）取代全粗體；正體中文出版品偏愛此排版。
